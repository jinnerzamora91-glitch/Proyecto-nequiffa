Este proyecto es una simulación de la aplicación Nequi, desarrollada en Java, que permite administrar cuentas, realizar transacciones (retiros, recargas y envíos), y manejar diferentes tipos de bancos con sus respectivas comisiones.

El sistema incluye herencia, composición, agregación e interfaces, aplicando principios de Programación Orientada a Objetos (POO).
